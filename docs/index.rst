OpenDose-PopPK
==============

**A modular, open-source Python framework for Population Pharmacokinetic / Pharmacodynamic (PopPK/PD) modelling.**

OpenDose-PopPK bridges classical compartmental pharmacology with modern statistical tools,
providing 1- and 2-compartment PK models, Monte Carlo population simulation,
covariate modelling, and Bayesian MAP individual estimation — all in a single
lightweight library.
